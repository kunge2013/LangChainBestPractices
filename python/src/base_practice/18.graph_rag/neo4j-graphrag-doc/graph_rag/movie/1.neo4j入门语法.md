

## Neo4j 学习教程：从入门到进阶

我将用一个**电影数据库**的完整例子，由浅入深地展示所有核心语法。

---

## 第一部分：数据建模（实体-关系-属性）

### 1.1 数据模型设计

```
实体（节点）：
- Movie（电影）：title, released, rating, tagline
- Person（人物）：name, born, gender
- Studio（制片厂）：name, country

关系（Relationship）：
- ACTED_IN（出演）：roles（角色列表）
- DIRECTED（导演）：无属性
- PRODUCED（制片）：无属性
- WROTE（编剧）：无属性
- DISTRIBUTED_BY（发行）：year（发行年份）
```

### 1.2 创建约束（保证数据唯一性）

```cypher
// 1. 创建唯一性约束
CREATE CONSTRAINT movie_title_unique IF NOT EXISTS FOR (m:Movie) REQUIRE m.title IS UNIQUE;
CREATE CONSTRAINT person_name_unique IF NOT EXISTS FOR (p:Person) REQUIRE p.name IS UNIQUE;
CREATE CONSTRAINT studio_name_unique IF NOT EXISTS FOR (s:Studio) REQUIRE s.name IS UNIQUE;

// 2. 查看已创建的约束
SHOW CONSTRAINTS;
```

## 第二部分：创建数据（节点 + 关系）

### 2.1 创建电影节点

```cypher
// 创建 3 部电影
MERGE (m1:Movie {title: 'Inception'}) 
ON CREATE SET m1.released = 2010, m1.rating = 8.8, 
               m1.tagline = 'Your mind is the scene of the crime';

MERGE (m2:Movie {title: 'The Dark Knight'}) 
ON CREATE SET m2.released = 2008, m2.rating = 9.0, 
               m2.tagline = 'Why so serious?';

MERGE (m3:Movie {title: 'Interstellar'}) 
ON CREATE SET m3.released = 2014, m3.rating = 8.6, 
               m3.tagline = 'Mankind was born on Earth. It was never meant to die here.';
```

#### 2.1.1 查询所有节点和关系

~~~ cypher 
// 查询所有节点关系
MATCH (n)
OPTIONAL MATCH (n)-[r]-(d)
RETURN n, r, d
~~~

### 2.2 创建人物节点

```cypher
// 创建演员
MERGE (p1:Person {name: 'Leonardo DiCaprio'}) 
ON CREATE SET p1.born = 1974, p1.gender = 'Male';

MERGE (p2:Person {name: 'Christian Bale'}) 
ON CREATE SET p2.born = 1974, p2.gender = 'Male';

MERGE (p3:Person {name: 'Matthew McConaughey'}) 
ON CREATE SET p3.born = 1969, p3.gender = 'Male';

MERGE (p4:Person {name: 'Anne Hathaway'}) 
ON CREATE SET p4.born = 1982, p4.gender = 'Female';

// 创建导演
MERGE (p5:Person {name: 'Christopher Nolan'}) 
ON CREATE SET p5.born = 1970, p5.gender = 'Male';

// 创建演员（小角色）
MERGE (p6:Person {name: 'Michael Caine'}) 
ON CREATE SET p6.born = 1933, p6.gender = 'Male';
```

### 2.3 创建制片厂节点

```cypher
MERGE (s1:Studio {name: 'Warner Bros.'}) 
ON CREATE SET s1.country = 'USA';

MERGE (s2:Studio {name: 'Paramount Pictures'}) 
ON CREATE SET s2.country = 'USA';

MERGE (s3:Studio {name: 'Legendary Pictures'}) 
ON CREATE SET s3.country = 'USA';
```

### 2.4 创建关系

```cypher
// ============================================
// 第1步：创建/匹配所有节点（Person, Movie, Studio）
// ============================================

// 创建演员节点
MERGE (p1:Person {name: 'Leonardo DiCaprio'})
MERGE (p2:Person {name: 'Christian Bale'})
MERGE (p3:Person {name: 'Matthew McConaughey'})
MERGE (p4:Person {name: 'Anne Hathaway'})
MERGE (p5:Person {name: 'Christopher Nolan'})
MERGE (p6:Person {name: 'Michael Caine'})

// 创建电影节点
MERGE (m1:Movie {title: 'Inception'})
ON CREATE SET m1.released = 2010, m1.rating = 8.8

MERGE (m2:Movie {title: 'The Dark Knight'})
ON CREATE SET m2.released = 2008, m2.rating = 9.0

MERGE (m3:Movie {title: 'Interstellar'})
ON CREATE SET m3.released = 2014, m3.rating = 8.6, 
               m3.tagline = 'Mankind was born on Earth. It was never meant to die here.'

// 创建制片厂节点
MERGE (s1:Studio {name: 'Warner Bros.'})
MERGE (s2:Studio {name: 'Paramount Pictures'})
MERGE (s3:Studio {name: 'Legendary Pictures'})

// ============================================
// 第2步：创建所有关系
// ============================================

// ----- Inception (2010) 的关系 -----
// 演员
MERGE (p1)-[:ACTED_IN {roles: ['Cobb']}]->(m1)
MERGE (p6)-[:ACTED_IN {roles: ['Miles']}]->(m1)

// 导演 & 编剧
MERGE (p5)-[:DIRECTED]->(m1)
MERGE (p5)-[:WROTE]->(m1)

// 发行
MERGE (s1)-[:DISTRIBUTED_BY {year: 2010}]->(m1)

// ----- The Dark Knight (2008) 的关系 -----
// 演员
MERGE (p2)-[:ACTED_IN {roles: ['Bruce Wayne']}]->(m2)
MERGE (p6)-[:ACTED_IN {roles: ['Alfred']}]->(m2)

// 导演 & 编剧
MERGE (p5)-[:DIRECTED]->(m2)
MERGE (p5)-[:WROTE]->(m2)

// 发行
MERGE (s1)-[:DISTRIBUTED_BY {year: 2008}]->(m2)
MERGE (s3)-[:DISTRIBUTED_BY {year: 2008}]->(m2)

// ----- Interstellar (2014) 的关系 -----
// 演员
MERGE (p3)-[:ACTED_IN {roles: ['Cooper']}]->(m3)
MERGE (p4)-[:ACTED_IN {roles: ['Brand']}]->(m3)
MERGE (p6)-[:ACTED_IN {roles: ['Professor Brand']}]->(m3)

// 导演 & 编剧
MERGE (p5)-[:DIRECTED]->(m3)
MERGE (p5)-[:WROTE]->(m3)

// 发行
MERGE (s1)-[:DISTRIBUTED_BY {year: 2014}]->(m3)
MERGE (s2)-[:DISTRIBUTED_BY {year: 2014}]->(m3)
```


### 2.5 验证数据

```cypher
// 查看所有节点
MATCH (n) RETURN n;

// 查看所有关系
MATCH ()-[r]->() RETURN r;

// 查看完整图谱
MATCH (n) OPTIONAL MATCH (n)-[r]-(m) RETURN n, r, m;
```

## 第三部分：基础查询（简单查询）

### 3.1 查询所有数据

```cypher
// 1. 查询所有电影
MATCH (m:Movie) RETURN m;

// 2. 查询所有人
MATCH (p:Person) RETURN p;

// 3. 查询所有制片厂
MATCH (s:Studio) RETURN s;

// 4. 返回特定属性（投影）
MATCH (m:Movie) 
RETURN m.title AS 电影名称, m.released AS 上映年份, m.rating AS 评分;
```

### 3.2 精确查询

```cypher
// 1. 查询特定电影
MATCH (m:Movie {title: 'Inception'}) 
RETURN m;

// 2. 查询特定人物
MATCH (p:Person {name: 'Christopher Nolan'}) 
RETURN p.name, p.born, p.gender;

// 3. 查询特定制片厂
MATCH (s:Studio {name: 'Warner Bros.'}) 
RETURN s;
```

### 3.3 条件查询（WHERE）

```cypher
// 1. 查询评分大于 8.5 的电影
MATCH (m:Movie) 
WHERE m.rating > 8.5 
RETURN m.title, m.rating 
ORDER BY m.rating DESC;

// 2. 查询 2010 年以后上映的电影
MATCH (m:Movie) 
WHERE m.released >= 2010 
RETURN m.title, m.released;

// 3. 查询评分在 8.0 到 9.0 之间的电影
MATCH (m:Movie) 
WHERE m.rating >= 8.0 AND m.rating <= 9.0 
RETURN m.title, m.rating;

// 4. 查询 2000-2010 年间的电影
MATCH (m:Movie) 
WHERE m.released >= 2000 AND m.released <=2010 
RETURN m.title, m.released;
```

## 第四部分：模糊查询

### 4.1 使用 CONTAINS、STARTS WITH、ENDS WITH

```cypher
// 1. 查询标题包含 'dark' 的电影（不区分大小写）
MATCH (m:Movie) 
WHERE toLower(m.title) CONTAINS 'dark' 
RETURN m.title;

// 2. 查询以 'The' 开头的电影
MATCH (m:Movie) 
WHERE m.title STARTS WITH 'The' 
RETURN m.title;

// 3. 查询名字以 'Leon' 开头的人物
MATCH (p:Person) 
WHERE p.name STARTS WITH 'Leon' 
RETURN p.name;

// 4. 查询名字包含 'nolan' 的人物
MATCH (p:Person) 
WHERE toLower(p.name) CONTAINS 'nolan' 
RETURN p.name;
```

### 4.2 使用正则表达式

```cypher
// 1. 查询名字包含 'a' 且以 'e' 结尾的人物
MATCH (p:Person) 
WHERE p.name =~ '.*a.*e$' 
RETURN p.name;

// 2. 查询名字以 'C' 或 'L' 开头的人物（不区分大小写）
MATCH (p:Person) 
WHERE p.name =~ '(?i)^[CL].*' 
RETURN p.name;

// 3. 查询评分包含 .8 的电影（如 8.8, 9.8）
MATCH (m:Movie) 
WHERE m.rating =~ '.*\\.8$' 
RETURN m.title, m.rating;
```

## 第五部分：关系查询（核心）

### 5.1 单层关系查询

```cypher
// 1. 查询 Inception 的演员
MATCH (p:Person)-[:ACTED_IN]->(m:Movie {title: 'Inception'}) 
RETURN p.name AS 演员, p.born AS 出生年份;

// 2. 查询 Inception 的导演
MATCH (p:Person)-[:DIRECTED]->(m:Movie {title: 'Inception'}) 
RETURN p.name AS 导演;

// 3. 查询所有导演及其电影
MATCH (p:Person)-[:DIRECTED]->(m:Movie) 
RETURN p.name AS 导演, collect(m.title) AS 导演作品;

// 4. 查询 Leonardo DiCaprio 演过哪些电影
MATCH (p:Person {name: 'Leonardo DiCaprio'})-[:ACTED_IN]->(m:Movie) 
RETURN m.title AS 电影, m.released AS 上映年份;

// 5. 查询 Christopher Nolan 导演的所有电影
MATCH (p:Person {name: 'Christopher Nolan'})-[:DIRECTED]->(m:Movie) 
RETURN m.title, m.released, m.rating 
ORDER BY m.released DESC;
```

### 5.2 带关系属性的查询

```cypher
// 1. 查询 Inception 中所有演员及其角色
MATCH (p:Person)-[r:ACTED_IN]->(m:Movie {title: 'Inception'}) 
RETURN p.name AS 演员, r.roles AS 角色;

// 2. 查询 Warner Bros. 发行的所有电影及发行年份
MATCH (s:Studio {name: 'Warner Bros.'})-[r:DISTRIBUTED_BY]->(m:Movie) 
RETURN m.title AS 电影, r.year AS 发行年份;

// 3. 查询特定角色（如 'Cooper'）
MATCH (p:Person)-[:ACTED_IN {roles: ['Cooper']}]->(m:Movie) 
RETURN p.name, m.title;
```

### 5.3 多层关系查询（重要！）

```cypher
// 1. 查询与 Leonardo DiCaprio 合作过的其他演员
MATCH (p1:Person {name: 'Leonardo DiCaprio'})-[:ACTED_IN]->(m:Movie)<-[:ACTED_IN]-(p2:Person) 
WHERE p1 <> p2 
RETURN p2.name AS 合作演员, collect(m.title) AS 共同出演电影;

// 2. 查询 Christopher Nolan 合作过的所有演员
MATCH (director:Person {name: 'Christopher Nolan'})-[:DIRECTED]->(m:Movie)<-[:ACTED_IN]-(actor:Person) 
RETURN DISTINCT actor.name AS 演员, count(m) AS 合作电影数 
ORDER BY count(m) DESC;

// 3. 查询 Warner Bros. 发行的电影的所有导演
MATCH (s:Studio {name: 'Warner Bros.'})-[:DISTRIBUTED_BY]->(m:Movie)<-[:DIRECTED]-(p:Person) 
RETURN p.name AS 导演, collect(m.title) AS 电影;

// 4. 查询导演 Christopher Nolan 电影的制片厂
MATCH (p:Person {name: 'Christopher Nolan'})-[:DIRECTED]->(m:Movie)<-[:DISTRIBUTED_BY]-(s:Studio) 
RETURN DISTINCT s.name AS 发行公司;
```

### 5.4 路径查询（Path）

```cypher
// 1. 查询 Christopher Nolan 到 Leonardo DiCaprio 的路径
MATCH p = (n1:Person {name: 'Christopher Nolan'})-[*1..3]-(n2:Person {name: 'Leonardo DiCaprio'}) 
RETURN p;

// 2. 查询最短路径
MATCH p = shortestPath((n1:Person {name: 'Christopher Nolan'})-[*]-(n2:Person {name: 'Leonardo DiCaprio'})) 
RETURN p;

// 3. 查询所有长度为 2 的路径（导演-电影-演员）
MATCH p = (n1:Person)-[:DIRECTED]->(m:Movie)<-[:ACTED_IN]-(n2:Person) 
RETURN n1.name AS 导演, m.title AS 电影, n2.name AS 演员 
LIMIT 10;
```

## 第六部分：聚合查询（统计）

```cypher
// 1. 统计每个导演的电影数量
MATCH (p:Person)-[:DIRECTED]->(m:Movie) 
RETURN p.name AS 导演, count(m) AS 电影数量 
ORDER BY count(m) DESC;

// 2. 统计每个演员出演的电影数量
MATCH (p:Person)-[:ACTED_IN]->(m:Movie) 
RETURN p.name AS 演员, count(m) AS 出演电影数 
ORDER BY count(m) DESC;

// 3. 统计每部电影的演员数量
MATCH (p:Person)-[:ACTED_IN]->(m:Movie) 
RETURN m.title AS 电影, count(p) AS 演员数量;

// 4. 统计每个制片厂发行的电影数量
MATCH (s:Studio)-[:DISTRIBUTED_BY]->(m:Movie) 
RETURN s.name AS 制片厂, count(m) AS 电影数量;

// 5. 计算所有电影的平均评分
MATCH (m:Movie) 
RETURN avg(m.rating) AS 平均评分, min(m.rating) AS 最低分, max(m.rating) AS 最高分;

// 6. 每年上映的电影数量
MATCH (m:Movie) 
RETURN m.released AS 年份, count(m) AS 电影数量 
ORDER BY m.released;
```

## 第七部分：更新操作（SET）

### 7.1 更新节点属性

```cypher
// 1. 更新单个属性
MATCH (m:Movie {title: 'Inception'}) 
SET m.rating = 9.0 
RETURN m.title, m.rating;

// 2. 更新多个属性
MATCH (m:Movie {title: 'Inception'}) 
SET m.rating = 8.8, m.budget = 160000000 
RETURN m;

// 3. 添加新属性
MATCH (p:Person {name: 'Christopher Nolan'}) 
SET p.nationality = 'British' 
RETURN p;

// 4. 更新人物（使用 ON CREATE 和 ON MATCH）
MERGE (p:Person {name: 'Leonardo DiCaprio'}) 
ON CREATE SET p.born = 1974 
ON MATCH SET p.lastUpdated = date() 
RETURN p;
```

### 7.2 更新关系属性

```cypher
// 1. 更新关系属性
MATCH (s:Studio {name: 'Warner Bros.'})-[r:DISTRIBUTED_BY]->(m:Movie {title: 'Inception'}) 
SET r.year = 2010, r.region = 'Worldwide' 
RETURN r;

// 2. 添加关系属性
MATCH (p:Person {name: 'Leonardo DiCaprio'})-[r:ACTED_IN]->(m:Movie {title: 'Inception'}) 
SET r.salary = 20000000 
RETURN r;
```

### 7.3 条件更新（CASE WHEN）

```cypher
// 1. 根据条件更新评分
MATCH (m:Movie) 
SET m.rating = CASE 
    WHEN m.rating >= 9.0 THEN 'Excellent'
    WHEN m.rating >= 8.5 THEN 'Good'
    ELSE 'Average'
END 
RETURN m.title, m.rating;

// 2. 根据上映年份添加标签
MATCH (m:Movie) 
SET m.era = CASE 
    WHEN m.released < 2010 THEN 'Classic'
    ELSE 'Modern'
END 
RETURN m.title, m.released, m.era;
```

## 第八部分：插入和更新关系

### 8.1 插入新关系

```cypher
// 1. 为已有节点创建新关系
MATCH (p:Person {name: 'Michael Caine'})
MATCH (m:Movie {title: 'Inception'})
MERGE (p)-[:ACTED_IN {roles: ['Miles']}]->(m);

// 2. 创建不存在的关系（安全创建）
MERGE (p:Person {name: 'Christian Bale'})-[r:ACTED_IN {roles: ['Bruce Wayne']}]->(m:Movie {title: 'The Dark Knight'})
ON CREATE SET r.character = 'Batman'
RETURN r;

// 3. 批量插入关系
MATCH (p:Person {name: 'Christopher Nolan'})
MATCH (m:Movie)
WHERE m.title IN ['Inception', 'The Dark Knight', 'Interstellar']
MERGE (p)-[:PRODUCED]->(m);

// 4. 删除旧关系并创建新关系
MATCH (p:Person {name: 'Christopher Nolan'})-[r:WROTE]->(m:Movie {title: 'Inception'})
DELETE r
MERGE (p)-[:CO_WROTE]->(m);
```

### 8.2 更新关系

```cypher
// 1. 更新关系属性
MATCH (p:Person {name: 'Leonardo DiCaprio'})-[r:ACTED_IN]->(m:Movie {title: 'Inception'})
SET r.roles = ['Dominick Cobb', 'The Extractor']
RETURN r;

// 2. 添加关系属性
MATCH (p:Person {name: 'Christian Bale'})-[r:ACTED_IN]->(m:Movie {title: 'The Dark Knight'})
SET r.year = 2008, r.character = 'Batman'
RETURN r;

// 3. 批量更新关系属性
MATCH (p:Person)-[r:ACTED_IN]->(m:Movie)
WHERE m.released > 2010
SET r.after_2010 = true
RETURN p.name, m.title, r.after_2010;
```

## 第九部分：删除操作

### 9.1 删除属性

```cypher
// 1. 删除节点属性
MATCH (m:Movie {title: 'Inception'}) 
REMOVE m.budget 
RETURN m;

// 2. 删除关系属性
MATCH (p:Person {name: 'Leonardo DiCaprio'})-[r:ACTED_IN]->(m:Movie {title: 'Inception'}) 
REMOVE r.salary 
RETURN r;
```

### 9.2 删除关系

```cypher
// 1. 删除特定关系
MATCH (p:Person {name: 'Christopher Nolan'})-[r:PRODUCED]->(m:Movie {title: 'Inception'}) 
DELETE r;

// 2. 删除所有 DIRECTED 关系
MATCH (p:Person)-[r:DIRECTED]->(m:Movie) 
DELETE r;

// 3. 删除多个关系
MATCH (p:Person {name: 'Christopher Nolan'})-[r:WROTE]->(m:Movie) 
DELETE r;
```

### 9.3 删除节点

```cypher
// 1. 删除孤立节点（必须先删除关系）
MATCH (p:Person {name: 'Michael Caine'}) DETACH DELETE p;
// 或先删除关系再删除节点
MATCH (p:Person {name: 'Michael Caine'})-[r]-() DELETE r, p;

// 2. 删除所有 Movie 节点
MATCH (m:Movie) DETACH DELETE m;

// 3. 删除特定条件的节点
MATCH (m:Movie) 
WHERE m.rating < 8.0 
DETACH DELETE m;
```

## 第十部分：高级查询（综合应用）

### 10.1 复杂条件查询

```cypher
// 1. 查询评分 > 8.5 且上映于 2010 年后的电影
MATCH (m:Movie) 
WHERE m.rating > 8.5 AND m.released >= 2010 
RETURN m.title, m.rating, m.released;

// 2. 查询 Warner Bros. 发行的高分电影（评分 > 8.8）
MATCH (s:Studio {name: 'Warner Bros.'})-[:DISTRIBUTED_BY]->(m:Movie) 
WHERE m.rating > 8.8 
RETURN m.title, m.rating 
ORDER BY m.rating DESC;

// 3. 查询同时出演 Inception 和 The Dark Knight 的演员
MATCH (p:Person)-[:ACTED_IN]->(m1:Movie {title: 'Inception'})
MATCH (p)-[:ACTED_IN]->(m2:Movie {title: 'The Dark Knight'})
RETURN p.name AS 演员;

// 4. 查询与 Christopher Nolan 合作超过 1 次的演员
MATCH (p:Person {name: 'Christopher Nolan'})-[:DIRECTED]->(m:Movie)<-[:ACTED_IN]-(actor:Person)
WITH actor, count(m) AS movies
WHERE movies > 1
RETURN actor.name AS 演员, movies AS 合作次数;
```

### 10.2 EXISTS 子查询

```cypher
// 1. 查询有演员出演的电影
MATCH (m:Movie) 
WHERE EXISTS { MATCH (p:Person)-[:ACTED_IN]->(m) } 
RETURN m.title;

// 2. 查询有高分演员的电影
MATCH (m:Movie) 
WHERE EXISTS { 
    MATCH (p:Person)-[:ACTED_IN]->(m) 
    WHERE p.born < 1960 
} 
RETURN m.title;
```

### 10.3 列表操作

```cypher
// 1. 收集所有演员
MATCH (p:Person)-[:ACTED_IN]->(m:Movie {title: 'Inception'}) 
RETURN collect(p.name) AS 演员列表;

// 2. 展开列表
MATCH (p:Person)-[:ACTED_IN]->(m:Movie) 
RETURN m.title, p.name 
ORDER BY m.title;

// 3. 列表去重
MATCH (m:Movie)<-[:ACTED_IN]-(p:Person) 
RETURN m.title, collect(DISTINCT p.name) AS 演员;

// 4. 列表大小
MATCH (p:Person)-[:ACTED_IN]->(m:Movie) 
WITH m, collect(p.name) AS actors
WHERE size(actors) > 2
RETURN m.title, actors, size(actors) AS 演员数;
```

## 第十一部分：完整练习案例

### 11.1 查询场景

```cypher
// ===== 场景1：查找与 Christopher Nolan 合作过的所有演员 =====
MATCH (director:Person {name: 'Christopher Nolan'})-[:DIRECTED]->(m:Movie)<-[:ACTED_IN]-(actor:Person)
RETURN DISTINCT actor.name AS 合作演员
ORDER BY actor.name;

// ===== 场景2：查找评分最高的电影及其主创信息 =====
MATCH (m:Movie)
WHERE m.rating = (MAX { MATCH (m:Movie) RETURN m.rating })
OPTIONAL MATCH (p:Person)-[:ACTED_IN]->(m)
OPTIONAL MATCH (d:Person)-[:DIRECTED]->(m)
RETURN m.title, m.rating, collect(DISTINCT d.name) AS 导演, collect(DISTINCT p.name) AS 演员;

// ===== 场景3：演员网络 - 查找与 Leonardo DiCaprio 有共同演员的人 =====
MATCH (leo:Person {name: 'Leonardo DiCaprio'})-[:ACTED_IN]->(m:Movie)<-[:ACTED_IN]-(colleague:Person)
WHERE colleague <> leo
MATCH (colleague)-[:ACTED_IN]->(otherMovie:Movie)<-[:ACTED_IN]-(common:Person)
WHERE common <> leo AND common <> colleague
RETURN leo.name, colleague.name AS 合作演员, common.name AS 共同朋友, otherMovie.title AS 关联电影
LIMIT 20;

// ===== 场景4：查询 Warner Bros. 发行的所有电影及其导演和评分 =====
MATCH (s:Studio {name: 'Warner Bros.'})-[:DISTRIBUTED_BY]->(m:Movie)<-[:DIRECTED]-(d:Person)
OPTIONAL MATCH (m)<-[:ACTED_IN]-(a:Person)
RETURN m.title AS 电影, m.rating AS 评分, d.name AS 导演, collect(a.name) AS 演员
ORDER BY m.rating DESC;
```

### 11.2 更新场景

```cypher
// ===== 场景1：批量更新 - 为所有评分 > 8.8 的电影添加 'Oscar' 标签 =====
MATCH (m:Movie)
WHERE m.rating > 8.8
SET m.award = 'Oscar Nominated'
RETURN m.title, m.rating, m.award;

// ===== 场景2：条件更新 - 根据演员数量更新电影热度 =====
MATCH (m:Movie)<-[:ACTED_IN]-(p:Person)
WITH m, count(p) AS actorCount
SET m.popularity = CASE 
    WHEN actorCount >= 3 THEN 'High'
    WHEN actorCount >= 2 THEN 'Medium'
    ELSE 'Low'
END
RETURN m.title, actorCount, m.popularity;

// ===== 场景3：删除并重连关系 =====
// 删除错误的 DIRECTOR 关系，创建新的
MATCH (wrong:Person {name: 'Leonardo DiCaprio'})-[r:DIRECTED]->(m:Movie)
DELETE r
WITH m
MATCH (correct:Person {name: 'Christopher Nolan'})
MERGE (correct)-[:DIRECTED]->(m);
```

## 📚 语法速查表

| 操作类型 | 语法 | 说明 |
|---------|------|------|
| **创建节点** | `CREATE (n:Label {prop: 'value'})` | 无条件创建 |
| **合并节点** | `MERGE (n:Label {prop: 'value'})` | 有则匹配，无则创建 |
| **创建关系** | `MERGE (a)-[:TYPE]->(b)` | 创建关系 |
| **查询节点** | `MATCH (n:Label) RETURN n` | 查询所有 |
| **精确查询** | `MATCH (n:Label {prop: 'value'})` | 按属性查询 |
| **条件查询** | `WHERE n.prop > value` | 过滤条件 |
| **模糊查询** | `WHERE n.prop CONTAINS 'value'` | 包含子串 |
| **正则查询** | `WHERE n.prop =~ '.*value.*'` | 正则匹配 |
| **关系查询** | `(a)-[:TYPE]->(b)` | 查询关系 |
| **多层查询** | `(a)-[:TYPE1]->()-[:TYPE2]->(b)` | 多层关系 |
| **路径查询** | `MATCH p = (a)-[*1..3]->(b)` | 路径模式 |
| **更新属性** | `SET n.prop = 'new value'` | 设置属性 |
| **删除属性** | `REMOVE n.prop` | 移除属性 |
| **删除关系** | `DELETE r` | 删除关系 |
| **删除节点** | `DETACH DELETE n` | 删除节点及关系 |
| **聚合函数** | `count()`, `collect()`, `avg()` | 统计聚合 |
| **排序** | `ORDER BY n.prop DESC` | 排序 |
| **限制** | `LIMIT 10` | 限制结果数 |
| **跳过** | `SKIP 10` | 跳过前N条 |
